# 자금이체 계좌 DB

첨부 원본.xls의 272개 중 관리부서가 법인팀·복지회인 51개를 제외한 221개를 저장했습니다.
계좌번호 순으로 정렬한 계좌명·계좌번호가 원본수정.xls와 모두 일치합니다.
법인 회계단위라는 이유로 제외하지는 않습니다. 관리부서를 기준으로 분류하므로 후원팀의 계좌 등은 유지됩니다.
계좌번호는 원래 형식과 선행 0을 유지하는 TEXT로 저장합니다.

초기 데이터는 accounts.sqlite3, 원본·비교 파일은 originals, 대조 결과는 import-report.json에 있습니다.
자료 설정에서 매달 원본을 업로드합니다. 정리된 두 열짜리 계좌 파일도 지원합니다.
사용자 바탕화면 settings/accounts/transfer_accounts.sqlite3에 월별 스냅샷과 활성 버전을 저장하며,
원본 사본은 같은 폴더의 originals에 보관합니다. 과거 목록은 삭제하지 않습니다.
변환할 수 없는 파일은 현재 활성 목록을 변경하지 않습니다.

입력 칸은 최대 440픽셀이며, 초기화는 입력값을 비웁니다.
생성한 문구 목록을 비우는 기능은 별도 버튼으로 유지합니다.
검증: `python tests/test_transfer_account_updates.py`
