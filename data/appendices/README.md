# 부속명세서 조회 자료

2025회계연도 재무상태표(30개 시트), 운영계산서(6개 시트) 순으로 조회합니다.
각 DB는 `scripts/import_statement_db.py`로 변환했으며 구조는 재무제표 DB와 같습니다.
원본은 originals에 보관하고, 조회는 balance.sqlite3 및 operation.sqlite3를 읽습니다.
프로그램을 배포할 때 이 두 DB를 같은 상대 경로로 포함해야 합니다.

원본 시트 순서, 좌표, 빈 행, 병합 셀, 숫자 표시 형식을 유지합니다.
수식은 DB에 원문과 캐시 값을 함께 저장하고 화면에는 원본에 저장된 계산 결과를 표시합니다.
프로그램에서 수식을 다시 계산하지는 않습니다. Excel의 전체 인쇄·디자인 서식을 재현하는 화면은 아닙니다.
헤더 클릭 정렬과 셀 수정은 지원하지 않습니다.

검증: `python tests/test_appendix_view.py`
36개 시트의 모든 화면 셀과 병합 범위를 원본(data_only=True)과 비교합니다.
