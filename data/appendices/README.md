# 부속명세서 조회 자료

2021~2025회계연도를 선택해 재무상태표(각 29개 시트), 운영계산서(각 6개 시트) 순으로 조회합니다.
조회 화면 상단의 시트 탭을 선택합니다. 드롭다운 없이 재무상태표 29개, 운영계산서 6개를
원본 순서로 나열하며, 넘치는 탭은 좌우 화살표로 이동합니다.
각 DB는 `scripts/import_statement_db.py`로 변환했으며 구조는 재무제표 DB와 같습니다.
원본은 originals에 보관하고, 조회는 balance.sqlite3 및 operation.sqlite3를 읽습니다.
프로그램을 배포할 때 이 두 DB를 같은 상대 경로로 포함해야 합니다.

조회는 Excel 객체를 만들지 않고 DB의 값을 직접 읽어 프로그램 전용 QAbstractTableModel에 전달합니다.
여러 줄로 된 열 제목은 한 줄의 열 이름으로 합치고, 빈 행은 제외합니다.
병합된 분류명은 각 데이터 행의 필드로 반복하며, 금액을 반복해 채우지는 않습니다.
원본 행 번호와 열 번호를 모델 데이터에 보존합니다. 숫자는 원값을 보관하고 화면에서는 천 단위 구분과
최대 소수 둘째 자리로 표시합니다. 툴팁에서는 반올림 전 값을 확인할 수 있습니다.
표의 글꼴·텍스트 크기·다크모드는 프로그램 공통 설정을 따릅니다.
수식은 DB에 원문과 캐시 값을 함께 저장하고 화면에는 원본에 저장된 계산 결과를 표시합니다.
프로그램에서 수식을 다시 계산하지는 않습니다. Excel의 전체 인쇄·디자인 서식을 재현하는 화면은 아닙니다.
헤더 클릭 정렬과 셀 수정은 지원하지 않습니다.

검증: `python tests/test_appendix_view.py`
35개 시트의 레코드 원값을 원본(data_only=True)과 비교하고, Excel 복원 없이 직접 조회되는지 확인합니다.
